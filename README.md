# BioLechuguín EC

Landing y modelo industrial de referencia para valorización de **lechuguín** retirado en embalses y represas (Ecuador), en marco **público-privado** con la Empresa Pública del Agua.

## Rutas

| Ruta | Contenido |
|------|-----------|
| `/` | Pitch: visión, problema, solución, ESG, alianzas |
| `/modelo-industrial` | Proceso paso a paso, áreas de planta y equipamiento referencial |

## Desarrollo

```bash
cd C:\Users\sheid\Documents\biojacinto-ec
npm install
npm run dev
```

- Inicio: [http://localhost:3000](http://localhost:3000)
- Modelo industrial: [http://localhost:3000/modelo-industrial](http://localhost:3000/modelo-industrial)

## Contenido editable

- [`src/content/pitch.ts`](src/content/pitch.ts) — textos del pitch
- [`src/content/industrialModel.ts`](src/content/industrialModel.ts) — pasos, equipos y áreas

## Notas

- El modelo industrial es **conceptual**; no sustituye ingeniería de detalle ni cotizaciones.
- No se incluyen contactos ficticios; la coordinación se describe como vía canales institucionales.
